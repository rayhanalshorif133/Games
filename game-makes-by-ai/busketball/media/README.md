# Media Assets Directory (Construct 3 Style)

This folder contains audio and sound resources.
The game includes a high-fidelity Web Audio API synthesizer (`scripts/audio.js`) which generates all realistic basketball sounds in real-time with zero latency and zero external dependencies:

- **bounce**: Hardwood court floor basketball thump
- **backboard**: Solid wooden/acrylic backboard rebound thud
- **rim**: Metallic steel hoop ring clank
- **swish**: Realistic cord net swish whoosh
- **cheer**: Stadium crowd roar and applause
- **countdown**: Final 10 seconds tick
- **buzzer**: End-of-game regulation arena horn
