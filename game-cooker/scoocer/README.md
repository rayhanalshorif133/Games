# ⚽ 2D Soccer Multiplayer Game

একটি আধুনিক এবং সম্পূর্ণ 2D মাল্টিপ্লেয়ার সকার গেম, যা **Construct 3 Build File Structure** অনুসরণ করে এইচটিএমএল৫ ক্যানভাস (HTML5 Canvas), মসৃণ পদার্থবিজ্ঞান (Physics), সাউন্ড সিন্থেসাইজার এবং রিয়েল-টাইম ৪-সংখ্যার রুম কোড মাল্টিপ্লেয়ার দিয়ে তৈরি করা হয়েছে।

---

## 🚀 কীভাবে গেমটি চালাবেন (How to Run)

### ১. সার্ভার চালু করা
টার্মিনালে বা কমান্ড প্রম্পটে নিচের কমান্ডটি লিখুন:
```bash
npm start
```
অথবা:
```bash
node server.js
```

কমান্ডটি রান করলে টার্মিনালে লোকাল এবং ল্যান (LAN) আইপি দেখতে পাবেন:
- **লোকাল লিংক (এই পিসিতে খেলার জন্য):** [http://localhost:3000](http://localhost:3000)
- **ওয়াইফাই/ল্যান লিংক (মোবাইল বা অন্য পিসিতে খেলার জন্য):** `http://<আপনার-আইপি>:3000`

## 🎮 কীভাবে মাল্টিপ্লেয়ার খেলবেন (How to Play Multiplayer)

1. **রুম তৈরি (Create Room):**
   - ১ম প্লেয়ার ব্রাউজারে গিয়ে **"CREATE ROOM"** বাটনে ক্লিক করবেন।
   - একটি ৪-সংখ্যার রুম কোড পাবেন (যেমন `4821`) এবং লবিতে অপেক্ষা করবেন।
   - কোডের পাশে থাকা **"COPY"** বাটনে ক্লিক করে কোডটি কপি করে বন্ধুর সাথে শেয়ার করুন।

2. **কোড দিয়ে জয়েন করা (Join With Code):**
   - ২য় প্লেয়ার অন্য ট্যাব, মোবাইল বা অন্য ডিভাইস থেকে **"JOIN WITH CODE"** এ যাবেন।
   - নাম এবং ৪-সংখ্যার কোডটি ইনপুট দিয়ে **"ENTER"** এ চাপলেই রুমে প্রবেশ করবেন।

3. **রেডি এবং ম্যাচ শুরু:**
   - উভয় প্লেয়ার **"READY"** বাটনে ক্লিক করবেন।
   - সাথে সাথে **3... 2... 1... GO!** কাউন্টডাউন শুরু হয়ে ম্যাচ শুরু হবে!

4. **সক্রিয় রুমের তালিকা (Show Room List):**
   - কে কে রুম খুলে রেখেছে তা দেখতে **"SHOW ROOM LIST"** এ ক্লিক করে সরাসরি ১-ক্লিকে যেকোনো রুমে জয়েন করা যাবে।

5. **অফলাইন মোডসমূহ:**
   - **🤖 PRACTICE VS AI:** একা স্মার্ট এআই রোবটের বিরুদ্ধে প্র্যাকটিস ম্যাচ।
   - **👥 LOCAL 2 PLAYER:** একই কিবোর্ড বা স্ক্রিনে ২ জন মিলে খেলা (WASD বনাম Arrow Keys)।

## 🎯 কন্ট্রোলস (Controls)

- **মাউস / টাচ:** মাউস ড্র্যাগ করে অথবা মোবাইলের স্ক্রিনে হাত বুলিয়ে সহজে প্যাডেল মুভ করুন।
- **কিবোর্ড:**
  - **প্লেয়ার ১:** `W`, `A`, `S`, `D` অথবা `Arrow Keys`
  - **প্লেয়ার ২:** `Arrow Keys`

## ✨ এফেক্টস এবং ভিজ্যুয়াল জুস (Visual & Sound Juice)

- **বল স্পিড ট্রেইল:** বল দ্রুত গতিতে চললে পেছনে গ্লোয়িং ট্রেইল তৈরি হয়।
- **প্যাডেল ইমপ্যাক্ট রিং & স্পার্কস:** প্যাডেলে বল আঘাত করলে শকওয়েভ রিং ও স্পার্ক তৈরি হয়।
- **গোল বিস্ফোরণ & কনফেটি:** গোল হলে ক্যামেরা কাঁপবে (Screen Shake) এবং হাজারো রঙের কনফেটি বিস্ফোরণ ঘটবে।
- **রেফারি হুইসেল & ক্রাউড সাউন্ড:** আসল রেফারির বাঁশি ও স্টেডিয়ামের গর্জন Web Audio সিন্থেসাইজারের মাধ্যমে কোনো বাহ্যিক অডিও ফাইল ছাড়াই লাইভ তৈরি হয়।

## 📁 Construct 3 বিল্ড ফাইল স্ট্রাকচার

```
scoocer/
├── Assets/                    # অরিজিনাল গ্রাফিক্স ও Fredoka ফন্ট
├── index.html                 # মূল গেম এন্ট্রি ও UI
├── style.css                  # রেসপনসিভ ডিজাইন ও স্টাইল
├── appmanifest.json           # Web App Manifest
├── offline.json               # Construct 3 স্টাইল অফলাইন ক্যাশ লিস্ট
├── sw.js                      # সার্ভিস ওয়ার্কার
├── server.js                  # Node.js HTTP + WebSocket মাল্টিপ্লেয়ার সার্ভার
├── package.json               # ডিপেন্ডেন্সি ও স্ক্রিপ্টস
└── scripts/
    ├── main.js                # গেম লুপ, ক্যানভাস ও রেন্ডারিং
    ├── game.js                # গেম স্টেট মেশিন ও লজিক
    ├── physics.js             # ক্যালিব্রেটেড ২ডি ফিজিক্স ও কলিশন
    ├── network.js             # ৪-সংখ্যার রুম কোড নেটওয়ার্কিং
    ├── effects.js             # কনফেটি, পার্টিকেলস ও স্ক্রিনশেক
    ├── audio.js               # ওয়েব অডিও সিন্থেসাইজার
    └── ui.js                  # মেনু, লবি ও এইচইউডি হ্যান্ডলার
```
